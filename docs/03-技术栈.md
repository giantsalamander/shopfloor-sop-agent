## 三、NVIDIA 模型
**Nemotron-3.5-Lightning-30B-A3B-NVFP4**（实测 config.json + vLLM 启动日志）
- 架构：NemotronH（Mamba/SSM + Transformer 混合），NemotronHForCausalLM
- 规模：52 层，hidden 2688，GQA 32 头/2 KV 头，MoE 每 token 激活 6 专家，30B 总参/约 3B 激活
- 量化：NVFP4（ModelOpt modelopt_mixed），KV cache fp8_e4m3
- 上下文：原生 1M（max_position_embeddings=1048576），实配 65536
- 角色：标准理解 / SOP 规划 / 合规判定 / 报告生成

## 四、StepFun 阶跃星辰模型
**Step3-VL-10B**（实测 config.json，HF: stepfun-ai/Step3-VL-10B）
- 架构：StepVLForConditionalGeneration（model_type=step_robotics）
- 视觉：ViT 式感知编码器（约 1.8B，patch/width/layers/heads/ls_init_value/ln_post）
- 文本：Qwen3-8B 风格解码器（rope_scaling/GQA/rms_norm）
- 连接：projector，16x 空间下采样（understand_projector_stride）
- 精度：bf16，权重 19GB（2 个 safetensors 分片）
- 角色：仪器面板读数 / 警示符号 / 现场照片结构化抽取
- vLLM 参数：--trust-remote-code（自带 configuration_step_vl.py）、--limit-mm-per-prompt 为 JSON 格式 image:16

## 七、关键版本兼容性记录（实测踩坑）
1. vLLM 0.29 的 --limit-mm-per-prompt 只收 JSON 格式，key=value 写法报参数错误。
2. guided_json（extra_body）对 Step3-VL 无效；response_format json_object 有效（两模型均验证）。
3. huggingface_hub 1.29 起 huggingface-cli 废弃，改用 hf download。
4. vLLM 启动依赖登录 shell 的 CUDA PATH（FlashInfer 运行时检查），非交互 shell 会报 backend not available。
5. claude.ai 安装源国内 geo-block；GitHub Release 走 ghfast.top 镜像（40KB/s → 13MB/s）。
